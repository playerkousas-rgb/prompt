# 做章 / 巾圈 / 紀念品 —— 領域筆記與設計提案

> 這份是動工前的功課：先把**童軍紀念章**與**巾圈**真正的做法、規格、限制搞懂，
> 再決定工作台要問哪些格、輸出什麼。紀念品排最後。
>
> 原則跟做卡一致：**我們的產品是那份 JSON**，使用者拿去 ChatGPT / Gemini / 即夢生圖，
> 附圖也在他們那邊做。所以輸出必須自帶「工藝常識」，因為生圖模型不懂「電繡繡不出 3mm 的字」。

## 一、童軍章的真實世界

### 1.1 章分兩種，設計邏輯完全不同

| | 制服章（階級章、技能章、團次章、縣市章） | 紀念章 / 活動章（我們要做的） |
|---|---|---|
| 誰決定長相 | 總會規定，不能亂改 | 團 / 活動自己設計 |
| 設計重點 | 辨識、統一 | 有梗、好看、值得收藏、可交換 |
| 常見尺寸 | 技能章 3–5 cm、階級／巡邏章 7–10 cm | 活動章 5–8 cm（背包、營帽、毯子） |
| 典型工藝 | 電繡斜紋布 | 電繡 / 織章 / PVC / 琺瑯金屬襟章 |

佩戴位置（設計時要先知道最後貼在哪，尺寸才對）：左胸 7–10 cm、右胸 6–8 cm、
臂章 3–5 cm、帽章 2–4 cm、背包與營毯 5–8 cm。([童軍徽章指南](https://artistembroidery.com/tw/%E7%AB%A5%E8%BB%8D%E5%BE%BD%E7%AB%A0%E6%8C%87%E5%8D%97/))

### 1.2 四種主流工藝，差別在「細節能做多細」

| 工藝 | 質感 | 最小可讀文字 | 耐候 | 適合 |
|---|---|---|---|---|
| **電繡（Embroidery）** | 立體針腳、傳統、厚實 | **5 mm 以上** | 好 | 制服章、階級章、經典活動章 |
| **織章（Woven）** | 平滑細緻、像布料印刷 | **2 mm 以上** | 中（薄，戶外易勾紗） | 有年份／小字／複雜線條的紀念章 |
| **PVC 軟膠** | 立體分層、色彩鮮豔 | **1.5 mm 以上** | 最好（防水好洗） | 夏令營、背包、雨衣 |
| **金屬琺瑯襟章** | 硬琺瑯＝鏡面平滑；軟琺瑯＝色塊下凹、金屬線浮凸 | 看模具，約 1 mm | 最好 | 交換用紀念襟章、領巾夾 |

([工藝對照表](https://pb-patch.com/custom-scout-patches/)、[刺繡線最小線寬約 1 條線 ≒ 1 mm](https://j6patches.com/designs))

### 1.3 幾個一定要問、但大家都會忘的規格

- **底布 vs 100% 滿繡**：斜紋布（twill）露底＝復古、省錢；100% 滿繡＝細節最多、最挺。
  50% / 75% / 100% 是報價的分水嶺。
- **邊緣**：
  - 包邊 / Merrow（傳統滾邊，**固定 3–4 mm 寬**）→ 只能用在圓、橢圓、方、標準盾形
  - 雷切 / 熱切（可做任意外形，邊可細到 1 mm）→ 異形章只能選這個
- **背膠五選一**：不背膠 / 硬膠 / 軟膠（熱熔，可燙貼，但尼龍、皮革、毛衣不適用）/
  自黏膠 / 魔鬼氈（公面在章背）。([背面處理](https://www.emblemandpin-tw.com/pd47995759.html))
- **顏色數**：電繡一般含 9–12 色；超過要加錢。Pantone 給色號比給圖準。
- **MOQ**：工廠普遍 100 片起跳 —— 這會影響使用者要不要做「一款多用」的設計。

### 1.4 設計上的鐵律（要寫進提示詞，模型才不會畫出做不出來的章）

1. 圖形要**大膽、少層次**，細線在刺繡會糊掉
2. 文字繞圈排（上緣中文、下緣英文或年份）是紀念章最穩的版型
3. 遠看要有辨識度：主色塊 ≥ 3，但總色數別爆
4. 童軍通用符號可借力：百合花徽（fleur-de-lis）、三葉草、繩結、指北針、營火、帳篷
5. 邊框要跟工藝一致：選了包邊就不要畫異形輪廓

## 二、巾圈（Woggle）

### 2.1 這東西的來歷（寫進產品文案會很加分）

- 早期童軍用單結綁領巾，容易皺；美國童軍先用骨頭、木頭、繩子做環，戲稱 *Boon Doggles*
- 1920 年代初，極偉園（Gilwell Park）工作人員 **Bill Shankley** 用老式縫紉機傳動皮繩做出
  **兩圈土耳其頭結**皮領圈，成為正式樣式
- 1923/6/9《Gilcraft》刊出〈Wear a scarf woggle〉，woggle 一詞自此流行；
  1929 年《Scouting for Boys》第 14 版正式使用 woggle（第 13 版還寫 ring）
- 1943–1989 年間，完成木章基本訓練者頒授**極偉皮領圈**

([領巾圈的由來](https://www.cnscout.org/index.php?c=show&id=343)、[木章溯源 極偉皮領圈](https://ylvsscout.pixnet.net/blog/post/34257627)、[What is a woggle](https://woggleapp.com/what-is-a-woggle/))

### 2.2 規格（這是巾圈工作台的「卡面尺寸」）

- **內徑**：約 19–22 mm（市售多標 3/4 inch ≒ 19 mm；3D 列印通用檔常用 **22 mm**）
- **高度 / 長度**：約 25 mm（1 inch）左右
- 太鬆會滑掉 —— 好的巾圈是「緊到不會自己滑下來」

([3/4 inch 內徑、1 inch 高](https://www.amazon.com/Handmade-Neckerchief-Leaders-Webelos-Paracord/dp/B0D2959HBQ)、[22 mm 內徑 3D 檔](https://makerworld.com/en/models/1421015-scout-woggle))

### 2.3 做法與材質（每一種要問的問題都不一樣）

| 類型 | 材料 | 關鍵參數 | 備註 |
|---|---|---|---|
| **編織結** | 皮繩 3–4 mm / 傘繩 550 / 打包帶 / 鋁線 / 竹篾 | 土耳其頭結 **幾瓣幾層**（3 lead 5 bight、七瓣三層…）、單色或雙色 | 最傳統，木章＝兩圈土耳其頭結皮領圈 |
| **皮雕片** | 植鞣皮 | 壓印圖案、鉚釘、壓扣 | 可打名字、可燙印團徽 |
| **木 / 竹** | 原木切片、雷雕 | 木紋方向、雷雕深度 | 可做名牌式吊牌 |
| **3D 列印** | PLA / 樹脂 | 內徑 22 mm、壁厚、單色好印 | 最適合「團徽立體化」 |
| **金屬 / 琺瑯** | 鋅合金壓鑄 | 開模費、硬／軟琺瑯 | 成本高、質感最好 |
| **樹脂 / 滴膠** | UV 膠、模具 | 包埋物（營火灰、沙、乾燥花） | 紀念性最強 |

([打包帶七瓣三層土耳其頭結](https://publication.scout.org.tw/scout-innovation/scout-cultural-creation-how-to-make-woggle-by-plastic-packing-belt/))

## 三、提案：三條產品線怎麼接進現在的架構

現在的引擎是 **schema 驅動**：一個系統 = `zones`（解剖圖區塊）+ `fields`（欄位）+ `build`（輸出）。
做章與巾圈完全可以沿用，UI 一行都不用改。

```
lib/badge/
  types.ts        沿用 lib/card/types.ts 的 FieldDef / ZoneDef（之後抽到 lib/schema/）
  systems/
    embroidery.ts 電繡章
    woven.ts      織章
    pvc.ts        PVC 軟膠章
    enamel.ts     金屬琺瑯襟章
    woggle.ts     巾圈
```

### 3.1 做章工作台：欄位分組（建議）

| 組 | 欄位 | 備註 |
|---|---|---|
| **用途** | 章的用途（活動章／團章／交換章／營期章）、佩戴位置、成品尺寸 | 位置自動建議尺寸 |
| **主視覺** | 主題一句話、核心物件（火山、營火、百合花…）、構圖（置中徽記／風景／吉祥物）、要不要人物或吉祥物 | |
| **文字** | 上緣中文、下緣英文、年份 / 屆數、團號 | **會依工藝自動檢查字高** |
| **風格** | 美術風格（復古徽章／扁平向量／日系吉祥物／線稿／擬真）、色盤（1–8 色，給 hex） | 沿用舊工具的色盤，但限制到 8 色內並提示「色數＝成本」 |
| **工藝** | 工藝（電繡／織章／PVC／硬琺瑯／軟琺瑯／滴膠）、底布（斜紋／毛氈／滿繡 %）、外形、邊緣（包邊／雷切）、背膠 | 外形與邊緣**互相鎖定** |

**解剖圖區塊**（中欄）：外輪廓 / 邊緣帶 / 上緣文字弧 / 主視覺區 / 下緣文字弧 / 年份徽記 / 底布 / 背膠（背面示意）。

### 3.2 做章的殺手鐧：**做得出來嗎？** 即時檢查

這是做卡沒有、但做章一定要有的東西。規則直接從上面的規格表來：

- 電繡 + 文字高度 < 5 mm → 「這行字繡出來會糊，建議改織章或放大」
- 包邊 + 異形輪廓 → 「包邊只能做圓／橢圓／方／盾形，異形請改雷切」
- 色數 > 9 → 「超過一般含色數，報價會跳」
- 尺寸 < 5 cm + 細節很多 → 「縮到這個尺寸細節會消失」
- 軟膠背膠 + 尼龍／皮革底材 → 「這類布料不能熱燙」

輸出的 JSON 會把這些寫成 `manufacturing_notes`，讓生圖模型**也**知道該畫成什麼樣。

### 3.3 輸出格式（草案）

```jsonc
{
  "subject": "2026 新界東區聯團大露營紀念章",
  "badge_type": "event commemorative patch",
  "craft": {
    "method": "100% embroidery on twill",
    "edge": "merrowed border, 3.5mm",
    "backing": "iron-on (hot melt)",
    "size_mm": 75,
    "thread_colors": 7
  },
  "composition": { "layout": "central emblem with text arcs", ... },
  "text": { "top_arc_zh": "…", "bottom_arc_en": "…", "year": "2026" },
  "palette": ["#0f5132", "#f6c445", "…"],
  "manufacturing_notes": [
    "Embroidered text must be at least 5mm tall; keep lettering bold and simple",
    "Merrowed border limits the silhouette to a true circle",
    "Render as a physical patch photographed flat on white, with visible stitch texture"
  ],
  "render": "studio product photo of the finished patch, flat lay, pure white background, visible thread texture, no mockup shadows",
  "negative_prompt": "…"
}
```

### 3.4 巾圈工作台

欄位：類型（編織結／皮雕／木／3D 列印／金屬／樹脂）→ 依類型顯示不同的格：

- 編織結 → 繩材、繩徑、瓣數層數（3L5B / 七瓣三層）、單色或雙色
- 3D 列印 → 團徽圖案、內徑（預設 22 mm）、壁厚、單色列印友善度
- 皮雕 → 壓印圖案、鉚釘／壓扣、皮色
- 共同 → 內徑、高度、要不要刻名字 / 團號 / 年份、佩戴在哪條領巾（配色）

解剖圖：正視圖（環身 + 正面徽牌）+ 側視圖（內徑、高度標註）。
輸出除了生圖提示詞，還可以多給一段**做法摘要**（土耳其頭結幾瓣幾層、要多長的繩）。

### 3.5 紀念品（最後一期）

先做章與巾圈，再擴到：領巾、營帽、徽章卡紙 / 收藏卡、紀念幣、鑰匙圈、
馬克杯、貼紙、T 恤、營火棒、名牌吊牌。這一塊的共通點是「同一套視覺跨多種載體」，
所以架構上應該是**一個視覺主題 → 多個載體輸出**，和做章的「一個章一份提示詞」不同，
留到最後做比較不會白寫。

## 四、動工前要你拍板的三件事

1. **做章第一版先做哪幾種工藝**：全上（電繡／織章／PVC／琺瑯）還是先做電繡＋織章？
2. **要不要輸出「廠商規格單」**：除了生圖提示詞，多一份可以直接貼給工廠的中文規格
   （尺寸、邊緣、背膠、色數、MOQ 提醒）。
3. **巾圈要不要附做法教學**：純生圖提示詞，還是連「土耳其頭結要準備 70 cm 打包帶」
   這種動手做的指引也一起輸出。
